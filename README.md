# vkit

Go 通用工具包，提供可复用的技术组件、工具函数和业务插件。

## 安装

```bash
go get github.com/ve-weiyi/vkit
```

## 目录结构

```
.
├── adapter/   # 外部服务适配器
├── x/         # 通用工具
├── plugins/   # HTTP 插件
├── gen/       # 代码生成
└── cmd/       # 人工执行的诊断程序
```

## 设计原则

- **adapter**：对接外部 SDK 或网络服务，有第三方依赖
- **x**：通用工具与轻量封装
- **plugins**：统一接口的 HTTP 插件，可独立挂载路由
- **gen**：代码生成工具，输出 `.go` 文件
- **cmd**：需要真实凭证或外网才能跑的诊断程序。这类验证会真实发信、上传文件或请求第三方站点，
  故从测试目录移出，保证 `go test ./...` 不触碰任何外部资源；凭证一律经环境变量传入。
